# Neonatal Intensive Care Unit Utilization and Outcomes in Denmark

Supplementary definitions and documentation for the nationwide Danish NICU study, 2020–2025.

## Contents

- `data-dictionaries/etable1_nicu_units_counts_2020_2025.csv`: SOR units and annual published admission counts (eTable 1).
- `code-lists/etable_s2_chronic_comorbidity_icd10.csv`: ICD-10 chronic comorbidity definitions (eTable S2).
- `code-lists/etable_s3_icd10_domains.csv`: ICD-10 chapter descriptions (eTable S3).
- `code-lists/etable_s4_neonatal_treatment_codes.csv`: neonatal treatment procedure codes (eTable S4).
- `code-lists/etable_s5_major_neonatal_morbidity_codes.csv`: major neonatal morbidity codes (eTable S5).
- `supplementary/supplement_as_submitted.docx`: original supplementary material.
- `docs/definitions.md`: interpretation notes and methodological caveats.


## Data availability and confidentiality

Individual-level register data are not included. These data are accessible only within authorized secure research environments.
